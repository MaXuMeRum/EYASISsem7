# Идентификатор языка PDF: Русский / Немецкий

Учебная система идентификации языка текстовых PDF-документов.

## Методы
1. **Коротких слов** — частотный словарь коротких функциональных слов.
2. **Алфавитный** — анализ характерных букв, биграмм и триграмм с учетом кириллицы/латиницы и немецких сочетаний.
3. **Нейросетевой** — многослойный перцептрон (MLP) из scikit-learn, обучаемый на встроенном учебном корпусе.

Система поддерживает:
- добавление одного или нескольких PDF;
- автоматическое извлечение текста;
- идентификацию каждого документа;
- активную ссылку на файл;
- сводную статистику по коллекции;
- сохранение результатов в TXT/CSV;
- печать отчета;
- встроенную справку;
- переобучение нейросетевого метода на пользовательском корпусе TXT.

## Запуск

### Windows
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

### Linux/macOS
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Важно про нейросетевой метод

В проект включен небольшой демонстрационный корпус для запуска "из коробки". Для лабораторной работы рекомендуется добавить собственные TXT-примеры русского и немецкого языка и нажать **Нейросетевой метод → Переобучить на корпусе**.

Формат корпуса:
```
corpus/
  ru/
    text1.txt
    text2.txt
  de/
    text1.txt
    text2.txt
```

## Структура
- `main.py` — запуск приложения.
- `app/` — исходный код.
- `corpus/` — учебные данные для MLP.
- `results/` — место для сохраненных отчетов.
- `tests/` — простой тест методов.

## Примечание
PDF должен содержать текстовый слой. Для сканированных изображений без OCR потребуется предварительно распознать текст.

### Печать
Печать реализована через `QTextDocument` и `QPageLayout`, что совместимо с актуальным API PySide6 и корректно выводит кириллицу/немецкие символы.
