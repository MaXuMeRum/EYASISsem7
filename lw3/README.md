# AutoRef — Sentence Extraction + OSTIS

Учебная система автоматического реферирования.

## Возможности
- Русский и немецкий языки
- Медицина
- Критика предметов изобразительного искусства
- Sentence Extraction
- OSTIS-like семантический граф
- Классический реферат
- Ключевые слова
- Сохранение TXT/HTML/JSON
- Печать
- Help
- Активная ссылка на исходный документ

## Установка

Для TXT дополнительные пакеты не нужны.

Для DOCX и PDF:

```bash
pip install python-docx pypdf
```

## Запуск

```bash
python autoref.py
```

## Примечание про OSTIS

В текущей версии реализован переносимый OSTIS-like семантический граф в JSON.
Это промежуточный формат для дальнейшего подключения к конкретной версии OSTIS/SC-machine.
