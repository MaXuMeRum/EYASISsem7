# СИП: русскоязычный логический поиск

Учебная информационно-поисковая система на Python.

## Возможности

- индексирование русскоязычных документов;
- лемматизация с `pymorphy3`;
- автоматическое выделение ключевых слов по формуле
  `A_ij = Q_ij * B_i`;
- `Q_ij` — число вхождений термина в документ;
- `B_i = ln(N / df_i)` — инверсная документная частота;
- логический поиск (`И`, `ИЛИ`, `НЕ`, скобки);
- естественно-языковой запрос без операторов автоматически трактуется как AND;
- активная ссылка на найденный документ;
- показ слов запроса, присутствующих в документе;
- оценка качества: Precision, Recall, F1, P@5, P@10, AP,
  R-Precision, nDCG@10;
- график Precision–Recall;
- веб-интерфейс, доступный в локальной сети;
- справочная страница.

## Установка

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Linux/macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

На компьютере, где запущено приложение:

`http://127.0.0.1:5000`

С другого компьютера в той же локальной сети:

`http://IP_КОМПЬЮТЕРА:5000`

Например: `http://192.168.1.25:5000`.

Если соединение блокируется, разрешите входящие подключения TCP к порту 5000
в брандмауэре ОС.

## Документы

Поместите файлы `.txt`, `.md`, `.pdf` или `.docx` в папку `documents`.
После этого откройте `/reindex` или пункт «Индекс» в интерфейсе.

## Пример запросов

- `информационный поиск`
- `информационный И поиск`
- `индексирование ИЛИ поиск`
- `поиск И НЕ интернет`
- `(информационный И поиск) ИЛИ индексирование`

## Важное замечание о логической модели

Булева модель определяет множество подходящих документов, но классически не
задаёт их ранжирование. Поэтому в программе вес `A_ij` применяется:
1. для автоматического выбора ключевых слов;
2. только как дополнительная сортировка документов, уже прошедших булево условие.

Это сохраняет логическую стратегию поиска и одновременно делает выдачу удобнее.

## Оценка качества

Для каждого тестового запроса эксперт заранее определяет, какие документы
релевантны. В меню «Оценка качества»:
1. введите запрос;
2. введите ID релевантных документов;
3. нажмите «Рассчитать метрики».

Для полноценного эксперимента лучше подготовить несколько запросов и эталонные
списки релевантности. MAP можно получить как среднее AP по этим запросам.
