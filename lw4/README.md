# Англо-русская система машинного перевода

Учебная система для варианта:

- направление: **английский -> русский**;
- предметная область 1: **научные статьи по медицине**;
- предметная область 2: **критика предметов изобразительного искусства**.

## Что реализовано

1. Ввод английского текста вручную.
2. Загрузка текста из PDF.
3. Машинный перевод EN -> RU.
4. Подсчёт слов во входном тексте.
5. Подсчёт переведённых слов.
6. Лемматизация и POS-анализ на базе `spaCy`.
7. Русская расшифровка POS-тегов.
8. Частотный словарь: лемма, частота, перевод, POS, предметная область.
9. Синтаксический разбор выбранного предложения:
   - Dependency Tree;
   - Constituency Tree при наличии Benepar.
10. SQLite-словарь с автоматическим пополнением.
11. Ручная корректировка словаря.
12. Сохранение результата в Unicode UTF-8 TXT.
13. Простой интерфейс PyQt6.

## Установка

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
python -m spacy download en_core_web_sm
```

Для Benepar при первом запуске модель может быть скачана автоматически.

Также для построения графов Graphviz должен быть установлен в ОС и команда `dot`
должна находиться в PATH.

## Запуск

```bash
python main.py
```

Для перевода через `deep-translator` требуется интернет-соединение.

## База данных

Файл `translator.db` создаётся автоматически.

Таблица `dictionary` содержит:

- lemma_en;
- translation_ru;
- pos;
- pos_description;
- domain;
- comment.

При обработке нового текста отсутствующее слово автоматически отправляется
в переводчик, после чего его перевод добавляется в SQLite.

## Важное замечание о подсчёте переведённых слов

В отчёте «переведённые слова» считаются как количество слов исходного текста,
для лемм которых система получила русский перевод из предметного словаря
или машинного переводчика.

Количество слов самого русского текста выводится отдельно.

## Соответствие лабораторным

Из лабораторной №1 использована идея:

- частотного подсчёта лемм;
- связи словоформа -> лемма;
- фильтрации словаря;
- ручного добавления/корректировки словарных записей.

Из лабораторной №3 использована функциональность:

- spaCy POS/морфологического анализа;
- dependency parsing;
- constituency parsing через Benepar;
- построения DOT-деревьев.
